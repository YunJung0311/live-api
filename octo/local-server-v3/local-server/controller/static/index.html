허용 없이 바로 붙이는 명령 (토큰 포함 — 단톡방 등에 올리지 말기)

2인치 화면 (전체)

작품은 각 Pi에서 제일 작은 화면(2인치)에 자동으로 뜸 — 모니터를 꽂아 둬도. 옆으로 누워 보이면 방향을 바꾸세요.

공용 API 키

기기에 개별 키가 없으면 이 키를 씀. 바꾼 뒤 Restart 해야 적용됨.
